# Pizza Cafe Pack

- Creator: Voloshka
- Source: https://viravoloshyn.itch.io/low-poly-cafe-asset
- Original download: `PizzaCafe.zip` (free Pizza Cafe Pack)
- Preserved source files: `assets-src/pizza-cafe/`
- Usage stated by the creator: free for personal and commercial projects

The original FBX contains 91 modular meshes that share one palette texture.
`tools/blender/split-pizza-cafe-assets.py` converts them into independent,
bottom-centered GLB files for this Three.js project. The texture is embedded in
each GLB so the exported files do not depend on the source folder at runtime.

Do not remove this source note when redistributing the project.
