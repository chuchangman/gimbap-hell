# 리팩토링 완료 기록

완료일: 2026-09-10

## 정리한 영역

- 게임 인원·이름·가게명·방 코드·복구 기본값을 `game-rules.js`로 통합했다.
- 서버 포트, 수용량, 소켓/HTTP, 종료 시간은 `runtime-config.mjs`로 분리했다.
- 랭킹 최대 200건과 재시도 정책은 `ranking-policy.mjs` 한 곳에서 JS와 Lua가 함께 쓴다.
- 주방 설비 기준점과 간격은 `kitchen-layout.js`가 렌더러와 서버 판정에 함께 제공한다.
- 카메라·시점·스윙 수치는 `render-config.js`로 묶고 이동 경계는 `MOVEMENT`를 재사용한다.
- 조리 중 색 변경 대상은 메시 교체 때 한 번 수집한다. 이전처럼 프레임마다 전체 트리를
  순회하지 않는다. 조준 raycast 결과 배열도 재사용한다.
- 설비 패널 생성과 로컬 QA 서버/대기/Playwright 탐색을 공용 helper로 정리했다.
- Blender 스크립트의 PC 절대 경로를 제거했다. 캐릭터는 현재 0.875 머리 축소율과
  X=±0.282, Y=1.255 어깨 피벗으로 다시 생성했다.

메시 교체 코드는 월드/카메라/아바타마다 부모와 자원 소유권이 달라 하나의 범용 함수로
억지로 합치지 않았다. 위치 보간처럼 매 프레임 달라지는 결과도 캐시하지 않았다.
